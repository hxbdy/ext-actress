# DMM Cast Auto-Filler

出演者不明の動画IDから出演者名を検索し、追記する。
追記した出演者名はアフィリエイトリンクに差し替える。

対象サイト: `https://video.dmm.co.jp/`（出演者名の参照元: `https://av-wiki.net/`）

> **本スクリプトはアダルトサイト向けです。18歳未満の方は利用しないでください。**

## アフィリエイトについて

本スクリプトは、**補完した女優名リンクおよびページ内の商品リンクを、作者のアフィリエイトID（`6dy-990`）付きのリンクに書き換えます。**
書き換えられたリンク経由で商品が購入された場合、作者に報酬が発生します。
この挙動が不要な場合はインストールしないでください。

## インストール

Chrome ウェブストアから削除されたため（理由は[下記](#chrome-ウェブストアからの削除について)）、ユーザースクリプトとして配布しています。

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) または [Violentmonkey](https://violentmonkey.github.io/) をインストールする
2. 以下のURLを開く
   https://raw.githubusercontent.com/hxbdy/actress-ext/main/dmm-cast-auto-filler.user.js
3. 表示されるインストール確認画面で内容を確認してインストールする

以降はユーザースクリプトマネージャが自動で更新を確認します。

## 使い方

インストール後、`video.dmm.co.jp` の作品ページを開くだけで動作します。

- 出演者欄が空、`----`、`＊＊＊` のいずれかの場合のみ、`av-wiki.net` を参照して出演者名を補完します
- すでに出演者名が入っているページは書き換えません
- 補完中は「取得中...」と表示され、見つからなかった場合は元の表示に戻ります

## 開発

`dmm-cast-auto-filler.user.js` の1ファイル構成です。
先頭の `DEBUG` を `true` にすると、動作ログがコンソールに出力されます。

## Chrome ウェブストアからの削除について

2026年8月、コンテンツポリシー違反（違反参照ID: Grey Lithium / 性的表現を含むコンテンツ）として Chrome ウェブストアから削除されました。
是正指示は「ポルノに関連するすべてのコンテンツまたはコードの削除」であり、本ツールの機能そのものと両立しないため、ストアへの再申請は行わず、ユーザースクリプトへ移行しました。

Chrome拡張機能としての最終版（v1.3）はコミット `c0dd501` 時点のものです。
