# DMM Cast Auto-Filler

出演者不明の動画ページに出演者名を追記します。
素人カテゴリにて効果を発揮します。

## インストール
1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) または [Violentmonkey](https://violentmonkey.github.io/) をインストールする
2. 以下のURLを開く
   https://raw.githubusercontent.com/hxbdy/actress-ext/main/dmm-cast-auto-filler.user.js
3. 表示されるインストール確認画面で内容を確認してインストールする

以降はユーザースクリプトマネージャが自動で更新を確認します。
github webhookにより通知しています。

## 使い方

インストール後、`video.dmm.co.jp` を開くだけで動作します。

### 作品ページ

- 出演者欄が空、`----`、`＊＊＊` のいずれかの場合のみ、出演者名を補完します
- 補完中は「取得中...」と表示され、見つからなかった場合は元の表示に戻ります
- 出演者名の下に、その出演者の他の素人作品を最大12件までサムネイルで表示します（av-wiki に女優ページがある出演者のみ）
- すでに出演者名が入っているページでも、av-wiki で他の素人作品を引ける出演者がいる場合は、名前と素人作品の表示に置き換えます
- 調べた出演作はブラウザに3日間記憶します

### 一覧ページ（素人トップ・一覧・ランキングなど）

- 各商品リンクの下に出演者名を表示します
- DMM側に出演者名がある作品は外部への問い合わせを行わず、元からある女優名リンクをアフィリエイトリンクに置き換えるだけです
- 一度調べた作品はブラウザに記憶し、再訪時は問い合わせません（見つかった作品は30日、未登録の作品は3日）

### 商品一覧ページ（`/list/`、`/av/list/` など）

- 「並び替え」欄の右隣に「BEST・ベスト除外」スイッチを表示します
- ON にすると、商品名に「BEST」「ベスト」を含む商品を一覧から隠し、隠した件数を横に表示します（英字の大文字・小文字・全角は区別しません）
- ON/OFF の状態はブラウザに記憶され、次回以降も引き継がれます

補完後のリンクはアフィリエイトリンクを含みます

## 開発

先頭の `DEBUG` を `true` にすると、動作ログがコンソールに出力されます。
